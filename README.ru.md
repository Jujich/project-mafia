# Деловая Мафия — панель ведущего

[English](README.md) | [Русский](README.ru.md)

Веб- и Android-приложение для ведущего очной игры «Мафия» по правилам клуба: подготовка партии, назначение ролей, ночные действия, обсуждение, голосование и завершение игры. Android-версия хранит игры на устройстве и работает без постоянного подключения к сети.

## Возможности

- Пятишаговый мастер подготовки игры с назначением и проверкой ролей.
- Пошаговое проведение ночи и дня с учётом специальных ролей, лечения и иммунитетов.
- Таймер обсуждения, восстанавливающийся после возвращения в приложение.
- Локальное хранение игр на Android и очередь синхронизации с повторами.
- Импорт снимков игры в PostgreSQL одной транзакцией с проверкой ревизий.
- Веб-вход ведущего и REST API с документацией Swagger.

Это инструмент ведущего очной игры. Синхронизация передаёт игры с Android на сервер; совместное редактирование и восстановление серверной истории на новом устройстве не реализованы. Общий мобильный токен ограничивает доступ к синхронизации, но не заменяет пользовательскую аутентификацию.

## Архитектура

| Каталог | Назначение | Технологии |
| --- | --- | --- |
| [`frontend/`](frontend) | Веб-панель, Nitro BFF и автономный Android-клиент | Nuxt 3, Vue 3, TypeScript, NuxtUI, Capacitor 8 |
| [`backend/`](backend) | Игровые правила, REST API, проверка и хранение снимков | NestJS, Prisma, PostgreSQL |

В браузере запросы проходят через Nitro с проверкой веб-сессии. Android использует локальный игровой движок и отправляет снимки через отдельный Nitro endpoint с мобильным токеном. Backend принимает более новые ревизии одной транзакцией: повторная отправка не создаёт дубликаты.

Основные части реализации:

- [Расчёт результатов ночи](backend/src/nights/night-resolution.ts) и [порядок ночных действий](backend/src/nights/night-steps.ts).
- [Локальный игровой движок](frontend/utils/offline-game-engine.ts) и [очередь синхронизации](frontend/utils/offline-sync-runner.ts).
- [Проверка снимков](backend/src/sync/sync-snapshot.ts) и [транзакционный импорт](backend/src/sync/sync.service.ts).

## Локальный запуск

Нужны Node.js 22 или новее, npm и работающий локальный PostgreSQL (в проекте использовалась версия 16). Зависимости frontend и backend устанавливаются отдельно.

### 1. База данных и окружение

От имени администратора PostgreSQL создайте локального пользователя и базу:

```sh
createuser --pwprompt mafia
createdb --owner=mafia mafia
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

В `backend/.env` настройте `DATABASE_URL` с адресом базы и выбранным паролем; оставьте `PORT=3000`. В `frontend/.env` задайте собственные `ADMIN_LOGIN` и `ADMIN_PASSWORD`, а для `NUXT_BACKEND_API_URL` оставьте `http://localhost:3000`. Замените примерные значения перед использованием. Файлы `.env` исключены из Git.

Для мобильной синхронизации задайте одинаковое отдельное случайное значение в backend `MOBILE_SYNC_TOKEN`, frontend `NUXT_MOBILE_SYNC_TOKEN` и параметре Android-сборки `NUXT_PUBLIC_MOBILE_SYNC_TOKEN`. Для локальной веб-версии сборка Android не требуется.

### 2. Backend

В первом терминале из корня репозитория:

```sh
cd backend
npm ci
npm run prisma:generate
npm run prisma:deploy
npm run start:dev
```

`prisma:deploy` применяет сохранённые миграции базы и не публикует приложение. API слушает порт `3000`, Swagger доступен по адресу `http://localhost:3000/api/docs`.

### 3. Frontend

Во втором терминале из корня репозитория:

```sh
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --port 3001
```

Откройте `http://localhost:3001` и войдите с данными из `frontend/.env`. Явный порт frontend исключает конфликт с backend. Проверка веб-входа выполняется в Nitro, поэтому прямой доступ к backend должен оставаться в вашей среде разработки.

## Android

Для нативной сборки нужны Node.js 22+, JDK 21 и Android SDK 36; приложение рассчитано на Android 7.0 и новее. После установки зависимостей frontend команда `npm run android:apk` из `frontend/` создаёт debug APK. Игровой процесс работает локально; синхронизации нужен ваш доступный HTTPS endpoint Nuxt и совпадающие мобильные токены.

Подробнее: [frontend, Android и синхронизация](frontend/README.ru.md), [backend, API и миграции](backend/README.ru.md). Готовые APK и ключи подписи в репозиторий не включены.
