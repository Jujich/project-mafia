# Установка «Деловой Мафии» на Android

Финальный файл для установки и передачи заказчику:
`artifacts/delovaya-mafia-1.0.0.apk`.

Приложение предназначено для **Android 7.0 и новее**. На iPhone APK не
устанавливается. Версия — `1.0.0`, код версии — `2`, package ID —
`ru.delovayamafia.host`. Интернет нужен для отправки статистики на сервер;
основной игровой процесс доступен без сети.

## Установка на свой телефон

Если на телефоне уже есть предыдущая тестовая версия, сначала прочитайте
раздел «Переход со старого debug APK» ниже.

1. Передайте `delovaya-mafia-1.0.0.apk` на телефон: например, отправьте себе
   в мессенджере **как файл/документ**, скачайте из доверенной ссылки или
   скопируйте по USB в папку «Загрузки».
2. Откройте APK на телефоне из «Загрузок» или файлового менеджера.
3. Если Android запросит разрешение устанавливать приложения из этого
   источника, разрешите его только тому приложению, из которого открыли
   доверенный APK. На Android 7 аналогичная настройка может называться
   «Неизвестные источники»; названия зависят от производителя.
4. Нажмите «Установить», затем «Открыть». После установки разрешение на
   установку из этого источника можно снова отключить.
5. Проверьте создание игры в авиарежиме. Затем включите сеть, вернитесь
   в приложение и дождитесь статуса «Данные синхронизированы» в шапке.
   Нажатие на статус повторяет отправку вручную.

Не отключайте антивирусную защиту или Google Play Защиту ради установки.
При предупреждении о вредоносном файле остановитесь и проверьте источник и
контрольную сумму. Общие рекомендации Google:
[установка приложений не из Google Play](https://support.google.com/android/answer/9457058?hl=ru).

## Как отправить заказчику

Отправьте **только** `delovaya-mafia-1.0.0.apk` как документ/файл в личном
сообщении либо дайте ссылку с ограниченным доступом. Не отправляйте архив
репозитория, `.credentials`, `.env`, ключи или файлы с паролями.

Короткий текст для заказчика:

> Прикладываю приложение «Деловая Мафия» для Android 7.0 и новее. Скачайте
> APK, откройте его и разрешите установку из используемого источника, если
> Android запросит разрешение. Играть можно без интернета; при восстановлении
> сети статистика отправляется автоматически. Если у вас уже установлена
> тестовая версия, не удаляйте её — сначала сообщите мне, чтобы сохранить
> данные игр.

## Переход со старого debug APK

**Не удаляйте старое приложение, если в нём есть несинхронизированные игры.**
Удаление приложения стирает его локальные данные.

Финальный release APK и прежний debug APK подписаны разными ключами.
Android не установит release поверх debug с тем же package ID. Это
[требование Android к подписи обновлений](https://developer.android.com/studio/publish/app-signing#considerations).

Для сохранения статистики предыдущей тестовой версии подготовлен отдельный
файл `artifacts/delovaya-mafia-1.0.0-debug-migration.apk`:

1. Установите **debug-migration APK поверх старой debug-версии**, не удаляя
   её. У файла та же debug-подпись и более высокий код версии.
2. Подключитесь к интернету и откройте приложение. Дождитесь статуса
   «Данные синхронизированы». При ошибке не удаляйте приложение: сначала
   нужно добиться успешной отправки и проверить наличие игр на сервере.
3. Только после подтверждения сохранения статистики можно удалить
   debug-версию и установить финальный `delovaya-mafia-1.0.0.apk`.

После удаления debug-версии **локальная история исчезнет**. Синхронизированная
статистика останется на сервере, но загрузка истории с сервера в новую
установку пока не предусмотрена. Если нужна именно локальная история,
сохраните debug-migration версию до согласования отдельного переноса данных.
Debug-migration — вспомогательная сборка для перехода, не финальный файл
для обычной раздачи заказчикам.

Будущие release-обновления, подписанные тем же release-ключом, устанавливаются
поверх финальной версии без удаления приложения и его данных.

## Проверенные параметры APK

Обе подписи успешно проверены `apksigner`; package ID, версия, SDK и
разрешения проверены `aapt`. Release не помечен как debuggable и подписан
отдельным release-сертификатом. Debug-migration подписан тем же Android Debug
сертификатом, что и предыдущий APK. Испытаний на реальном телефоне пока не было.

SHA-256 финального APK:

```text
c3ff6c373ba13bd88b7d9a1ec688d8b8827fdb4442bcf082b0576f4b8ddcced8
```

SHA-256 debug-migration APK:

```text
355d2f3127371e9ba06cb14d33029bc908f0af74558dbcfcf09686914b4b8484
```

## Для владельца проекта: резервная копия подписи

Приватно сохраните защищённую резервную копию этих файлов из корня проекта:

- `backend/.credentials/android/mafia-release.keystore`
- `backend/.credentials/android/release-signing.json`

Они нужны для выпуска будущих обновлений с той же подписью. Храните копию
в зашифрованном хранилище с ограниченным доступом, отдельно от Git и APK.
Не передавайте эти файлы заказчику вместе с приложением и не публикуйте их.
Потеря release-ключа лишит возможности выпускать обычные обновления поверх
установленной версии.
